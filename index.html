SUH Issue Helper
특징빠른 시작옵션예시GitHub

이슈에서 브랜치명과 커밋 메시지를 자동으로

GitHub 이슈가 생성되거나 제목이 수정될 때 브랜치명과 커밋 메시지를 만들어 댓글로 추가하는 GitHub Action입니다.

GitHub Actionv1.0.5MIT License
GitHub에서 보기빠른 시작

특징

이슈 제목 하나로 작업 시작 준비가 끝납니다.

브랜치명 자동 생성

날짜, 이슈 번호, 정규화된 제목으로 브랜치명을 만듭니다.

커밋 메시지 템플릿

템플릿을 직접 지정해 팀 규칙에 맞는 커밋 메시지를 만듭니다.

댓글 자동 갱신

이슈 제목이 바뀌면 댓글도 자동으로 갱신됩니다.

Private 저장소 지원

사용자 토큰을 넘기면 Private 저장소에서도 동작합니다.

한글·영문 제목 지원

한글과 영문 이슈 제목을 모두 처리합니다.

빠른 시작

워크플로우 파일 하나만 추가하면 됩니다.

프로젝트의 .github/workflows/issue-helper.yml 파일을 만듭니다.

.github/workflows/issue-helper.yml
name: Issue Helper - Generate Branch & Commit Messages

on:
  issues:
    types: [opened, edited]

permissions:
  issues: write
  contents: read

jobs:
  generate-comment:
    if: github.event.action == 'opened' || (github.event.action == 'edited' && github.event.changes.title)
    runs-on: ubuntu-latest
    steps:
      - name: Generate Branch & Commit Comment
        uses: Cassiiopeia/github-issue-helper@deploy
        with:
          token: ${{ secrets.GITHUB_TOKEN }}
          branch_prefix: "feat/"
          max_branch_length: 100
          commit_template: "${issueTitle} : feat : {변경 사항에 대한 설명} ${issueUrl}"

샘플 워크플로우는 저장소의 examples 폴더에서 기본 사용법, 커스터마이징, Private 저장소용 예시를 볼 수 있습니다.

입력 옵션과 출력값

모든 입력은 선택입니다.

입력값설명기본값
tokenGitHub 토큰 (빈 값이면 GITHUB_TOKEN 자동 사용)""
comment_marker댓글 업데이트를 위한 마커자동 생성 안내 주석
branch_prefix브랜치 접두사 (예: feat/)""
max_branch_length브랜치 기본 부분 최대 길이 (prefix 제외)"120"
commit_template커밋 메시지 템플릿"${issueTitle} : feat : {변경 사항에 대한 설명} ${issueUrl}"
출력값설명
branchName생성된 브랜치명
commitMessage생성된 커밋 메시지

템플릿 변수

  • ${issueTitle} 이슈 제목 (이모지와 태그 제거, 특수문자 유지)
  • ${issueUrl} 이슈 URL
  • ${issueNumber} 이슈 번호
  • ${branchName} 생성된 브랜치명
  • ${date} 날짜 (YYYYMMDD)

동작 예시

이슈 제목이 이렇게 바뀝니다.

이슈 제목: [Bug] 로그인 페이지에서 비밀번호 입력 오류

브랜치명
feat/20250917_#123_로그인_페이지에서_비밀번호_입력_오류
커밋 메시지
로그인 페이지에서 비밀번호 입력 오류 : feat : {변경 사항에 대한 설명} https://github.com/owner/repo/issues/123

정규화 규칙

  1. 태그 제거: [Bug], [Feature] 등의 태그를 제거합니다.
  2. 이모지 제거: 이모지와 제어 문자를 제거합니다.
  3. 특수문자 처리: 한글, 영문, 숫자를 제외한 문자는 _ 로 바꿉니다.
  4. 브랜치명 형식: {prefix}{YYYYMMDD}_#{issueNumber}_{normalizedTitle}
"Resource not accessible by integration" 오류가 나면
  1. 워크플로우에 permissions: issues: write, contents: read 를 추가합니다.
  2. Settings > Actions > General 의 Workflow permissions 를 Read and write permissions 로 바꿉니다.
  3. Private 저장소는 Personal Access Token(repo 권한)을 Secrets 에 등록하고 token 입력에 넘깁니다.
